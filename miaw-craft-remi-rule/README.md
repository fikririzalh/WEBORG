# MIAW-CRAFT REMI Edition

**Cat Go to Work: MIAW-CRAFT — Worker Deck Module v0.1**

Versi ini mengubah sistem Worker MIAW-CRAFT menjadi prototipe fisik menggunakan satu deck remi standar 52 kartu.

## Status versi

- Siap dipakai untuk playtest Worker, stack, adjacency, dan skill.
- Menggunakan 30 kartu Worker.
- 6 kartu menjadi Starting Workers.
- 24 kartu masuk Worker Deck setelah setup.
- Job Order dan scoring final **belum termasuk** pada v0.1. Modul tersebut direncanakan sebagai web companion MIAW-CRAFT Job Board.

## Isi folder

- `MIAW-CRAFT-REMI-RULEBOOK.md` — aturan lengkap Worker Deck Remi.
- `deck-list.csv` — daftar 30 kartu dan fungsi tiap kartu.
- `quick-reference.html` — referensi visual offline yang dapat dibuka di browser atau dicetak.

## Kebutuhan fisik

1. Satu deck remi standar 52 kartu.
2. Papan MIAW-CRAFT 19 hex atau 19 posisi yang digambar sendiri.
3. Beberapa koin/marker untuk prototipe bila diperlukan.
4. Sticky note kecil atau card sleeve untuk menandai enam Dual Worker.

## Prinsip pemetaan

- Rank kartu menentukan profesi.
- Suit hanya membedakan salinan Worker reguler.
- A = Baker.
- 2 = Recruiter.
- 3 = Courier.
- 4 = Mechanic.
- 5 = Barista.
- 6 = Manager.
- Enam kartu tertentu dari rank 7–8 = Dual Worker.

Buka `quick-reference.html` untuk referensi paling cepat di meja bermain.
