# Duel 52 — Cat Arena Lobby

Website statis HTML/CSS/JS yang menjelaskan aturan Duel 52 dalam Bahasa Indonesia dengan tema lobby game cerah, manis, dan maskot kucing.

## Cara menjalankan

1. Buka folder ini.
2. Klik dua kali `index.html`, atau buka melalui Live Server.
3. Tidak ada dependency eksternal; ilustrasi kucing dibuat sebagai SVG inline oleh JavaScript.

## Fitur

- Mode terang / gelap, tersimpan di localStorage.
- Navigasi sidebar ala game lobby.
- 13 kartu rank 2–A, masing-masing dengan ilustrasi kucing berbeda.
- Search dan filter tipe power.
- Modal detail tiap kartu.
- Simulator jumlah action.
- Responsive untuk desktop, tablet, dan mobile.
