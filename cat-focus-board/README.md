# Cat Focus Loop

Mini board game bergaya papan pantai yang dibuat dengan HTML, CSS, dan JavaScript murni.

## Fitur

- Papan permainan responsif dengan 28 petak
- Karakter kucing berjalan dan berputar terus mengelilingi papan
- Dua dadu interaktif
- Efek suara sintetis tanpa file audio eksternal
- Zoom masuk, zoom keluar, dan pas layar
- Mute / unmute
- Dark mode / light mode
- Fullscreen
- Kontrol keyboard
- Penghitung fokus, energi, bintang, dan misi kecil

## Cara menjalankan

Buka `index.html` langsung di browser modern. Tidak membutuhkan server atau instalasi paket.

## Kontrol

- `Space`: lempar dadu
- `+` / `-`: zoom
- `M`: mute

## Catatan

Visual dibuat sebagai karya orisinal yang mengambil inspirasi umum dari permainan papan digital, bukan menyalin aset, karakter, atau merek tertentu.
