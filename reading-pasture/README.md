# Reading Pasture · Lamb & Wolf Edition

Static offline reading-comprehension trainer built with HTML, CSS and vanilla JavaScript.

## Included
- 100 starter readings: 30 Level 1, 30 Level 2, 25 Level 3, 15 Level 4.
- Multiple-choice questions with detail, sequence, main idea, vocabulary, inference and purpose tasks.
- Three-step hints with score reduction.
- Evidence and explanation shown after checking.
- Vocabulary Barn derived from each reading.
- Full CRUD for readings, questions and vocabulary.
- JSON export/import.
- Local progress, score, streak and history.
- Light/dark farm theme and procedural Web Audio music/SFX.
- No server, npm package or database required.

## Run
Open `index.html` in a modern browser.

## Storage note
The 100-reading starter bank is text-only and small. The app stores the working bank and progress in localStorage. If you expand it into a very large library, consider IndexedDB.

## Level note
The four internal levels are pedagogical difficulty bands, not certified CEFR tests. Their progression is loosely informed by general CEFR reading progression and mainstream learner-reading practice.
