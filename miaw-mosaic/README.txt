MIAW MOSAIC: COZY CAT CAFÉ

CARA MENJALANKAN
1. Ekstrak miaw-mosaic.zip.
2. Buka folder miaw-mosaic.
3. Klik dua kali index.html.
4. Game akan terbuka di browser dan dapat dimainkan tanpa internet.

CARA BERMAIN
1. Pilih satu dari tiga patch di Rak Patch.
2. Klik satu hex kosong pada papan.
3. Penuhi pola tiga tamu kucing dan syarat tiga landmark.
4. Kelompok warna bersambung berisi minimal tiga patch memberi Cozy Charm.
5. Permainan selesai setelah 22 patch diletakkan.

KONTROL TAMBAHAN
- Segarkan: mengacak rak patch satu kali per permainan.
- Urungkan: membatalkan langkah terakhir satu kali per permainan.
- Cara main: membuka ringkasan aturan di dalam game.

FILE UTAMA
- index.html: file yang diklik untuk memainkan game.
- styles.css: tampilan game.
- game.js: mekanik dan perhitungan skor.
- mascot.png: aset maskot kucing barista.

Tidak diperlukan npm, instalasi, terminal, atau server lokal.
