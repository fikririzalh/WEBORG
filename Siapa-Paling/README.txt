SIAPA PALING — PARTY GAME OFFLINE

CARA MENJALANKAN
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka Siapa-Paling/index.html dengan browser. Biarkan app.js dan style.css di folder yang sama.
3. Masukkan nama pemain dan pilih mode permainan.

CARA BERMAIN
- Pass and play: satu ponsel berpindah tangan. Tiap orang memilih nama pemain lain tanpa terlihat.
- Narator + kertas: narator membaca pertanyaan, semua pemain (termasuk narator) menulis nama teman, lalu jumlah suara dimasukkan ke aplikasi.
- Nama dengan suara terbanyak mendapat gelar ronde itu. Jika seri, gelar dibagi. Identitas pemberi suara tidak dibuka.
- Pemain terpilih boleh membela diri selama 15 detik. Setelah 10 ronde, rekap gelar muncul.

FITUR
60 pertanyaan orisinal; 10 soal acak per permainan; tidak boleh memilih diri sendiri dalam mode pass and play; mode terang dan gelap; tombol kembali.

CATATAN
Game tidak memerlukan internet atau server setelah diekstrak. Jika browser membatasi penyimpanan untuk file lokal, game tetap dapat dimainkan, tetapi progres hilang bila tab ditutup atau dimuat ulang.
