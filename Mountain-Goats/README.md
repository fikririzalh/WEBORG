# Mountain Goats — companion satu perangkat

Fan companion tidak resmi untuk permainan dasar Mountain Goats, desain Stefan Risthaus / Allplay. Gunakan empat dadu fisik. Mendukung 2–4 pemain, enam gunung, perebutan puncak, persediaan token sesuai jumlah pemain, bonus set berulang, putaran terakhir dengan giliran seimbang, tie-break, Undo, riwayat, tema terang/gelap, dan simpan lokal.

Buka aplikasi, isi pemain, kelompokkan dadu di meja, lalu ketuk Naik sekali per kelompok bernilai 5–10. Aplikasi mempercayai validitas kelompok dadu. Maksimal empat aktivasi per giliran. Selesai giliran dapat ditekan tanpa gerakan jika tidak ada kelompok valid.

Tombol Unduh offline menghasilkan satu HTML mandiri untuk dibuka di browser tanpa internet. Penyimpanan tergantung dukungan browser, khususnya saat membuka file lokal. Tidak ada server permainan atau sinkronisasi antarperangkat. Unduhan memulai sesi sendiri, tidak menyalin progres perangkat asal.

Aplikasi masih dapat diperbarui secara berkala. Ekspansi dan validasi input dadu belum termasuk versi ini.

Sumber aturan: https://www.yucata.de/en/Rules/MountainGoats dan https://allplay.com/board-games/mountain-goats
