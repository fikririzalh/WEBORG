# My Study LMS Pribadi

Dashboard LMS dan to-do list bergaya gamifikasi yang dibuat dengan HTML, CSS, dan JavaScript murni.

## Cara menjalankan

1. Ekstrak folder proyek.
2. Buka `index.html` melalui browser.
3. Untuk pengalaman terbaik, jalankan melalui Live Server di VS Code.

## Fitur

- Tambah, edit, hapus, dan selesaikan tugas.
- Daftar subtugas interaktif.
- Progress otomatis berdasarkan subtugas.
- Catatan dengan penyimpanan otomatis.
- Filter Semua, Hari Ini, dan Selesai.
- Pencarian serta pengurutan tugas.
- XP, koin, target, dan ringkasan penyelesaian.
- Mode terang dan gelap.
- Data tersimpan pada `localStorage` browser.
- Layout responsif untuk desktop, tablet, dan ponsel.

Semua ikon dan ilustrasi utama dibuat tanpa ketergantungan gambar eksternal.
