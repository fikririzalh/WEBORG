# Sentence Pasture · Lamb & Wolf Edition

Static HTML/CSS/JS grammar trainer for sentence-completion questions.

## Included
- 100 starter questions, 25 per level
- 5-option multiple choice + “I don't know yet”
- Three-stage hints
- Explanation + grammar-frame feedback
- CRUD question bank
- JSON import/export
- Progress by level/category
- Light/dark pastoral theme
- Procedural Web Audio music/SFX
- localStorage persistence

## Run
Open `index.html` directly, or serve the folder with any static HTTP server.

## Notes
The four levels are internal practice levels, not standardized CEFR scores.
