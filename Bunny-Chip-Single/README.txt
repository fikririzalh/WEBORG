BUNNY STAKES - POKER CHIP TABLE
================================

Isi folder:
- index.html  : struktur aplikasi
- style.css   : seluruh tampilan dan responsivitas
- script.js   : logika pemain, chip, pot, transfer, dan penyimpanan

CARA MENJALANKAN
1. Ekstrak ZIP.
2. Buka folder hasil ekstraksi.
3. Klik dua kali index.html.
4. Aplikasi berjalan langsung di browser tanpa instalasi dan tanpa internet.

FITUR
- Tambah, edit, dan hapus pemain.
- Tambah atau kurangi saldo chip.
- Taruhan ke pot tengah.
- Transfer chip antar-pemain.
- Refund pot sesuai kontribusi.
- Pembagian pot kepada satu atau beberapa pemenang.
- Riwayat transaksi dan undo.
- Penyimpanan otomatis di browser.
- Tema terang/gelap dan suara umpan balik.

CATATAN DATA
Data disimpan melalui localStorage pada browser/perangkat yang digunakan.
Menghapus data situs atau cache browser dapat menghapus data meja.
