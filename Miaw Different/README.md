# MIAU! SAME OR DIFFERENT

2-player single-device social word deduction game.

## Flow
1. Pilih dua pemain.
2. Web memilih pasangan kata dan secara acak menentukan SAME atau DIFFERENT.
3. Jika SAME, kedua pemain mendapat kata yang sama. Jika DIFFERENT, masing-masing mendapat salah satu kata dari pasangan.
4. Kata dilihat secara privat dengan pass-the-phone.
5. Tiap clue round: Player A memberi clue verbal, lalu Player B.
6. Keduanya dapat memilih Decide atau tambah clue round sampai batas maksimum.
7. Keputusan SAME/DIFFERENT dibuat privat satu per satu.
8. Web membuka kedua keputusan secara simultan.
9. Jawaban benar = +1 poin. Pertama mencapai target menang.

## Fitur
- CRUD pemain P001...
- CRUD pasangan D001...
- 150 pair seed / 10 kategori
- SAME/DIFFERENT 50:50
- posisi kata A/B diacak
- target score 3/5/7
- max clue rounds 3/5/7
- dark/light
- sound
- localStorage
- export/import JSON
- responsive mobile
