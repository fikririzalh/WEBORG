# Error Recognition Pasture · Lamb & Wolf Edition

A local-first HTML/CSS/JavaScript practice companion for identifying grammatical errors in four marked sentence parts (A–D), inspired by the TOEFL ITP Written Expression task format.

## Included
- 100 original starter questions, 25 per internal level
- Four clickable underlined parts (A–D)
- One incorrect part per question
- Correction, explanation, grammar rule and 3-step hint ladder
- 25-question / 15-minute internal timed drill
- CRUD question bank
- JSON export/import
- Progress by level and grammar category
- Weak-area notebook
- Light/dark pastoral Lamb & Wolf theme
- Procedural music/SFX via Web Audio API
- LocalStorage persistence

## Important
This project is not affiliated with or endorsed by ETS. The starter questions are original. The timed drill and scores are internal training tools and are not official TOEFL scores.

## Run
Open `index.html` in a browser. For more consistent browser storage, serve the folder through any static web server rather than relying on `file://`.
