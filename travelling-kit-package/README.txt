TRAVELLING KIT — Web App
=========================

Cara pakai:
1. Buka file "index.html" langsung di browser (double klik), ATAU
2. Upload folder ini ke hosting statis apa pun (Netlify, Vercel, GitHub Pages, dll)
   lalu akses index.html.

Tidak perlu instalasi, server, atau internet setelah halaman terbuka —
semuanya berjalan di browser kamu. Data trip & kit tersimpan otomatis
di localStorage browser tempat kamu membukanya (jadi kalau pindah
browser/device, datanya tidak ikut pindah).

Fitur:
- Buat trip & checklist keberangkatan (kemas barang)
- Recheck kepulangan — otomatis deteksi barang yang tertinggal
- Kit template (Kit Pantai, Kit Kerja, Kit Camping + bisa bikin sendiri)
- Duplikat trip & simpan trip jadi kit baru
- Tema terang/gelap, palet warna resmi HAPPY PRISM

Selamat packing! 🐐
