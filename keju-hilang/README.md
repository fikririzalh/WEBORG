# Keju Hilang! — Cheese Thief web companion

Web companion penggemar untuk satu ponsel bersama. Membagikan peran dan angka dadu secara bergiliran, menyediakan intip angka saat malam, dan mendukung 4–8 pemain serta varian Fall Mouse. Tampilan responsif, tema terang/gelap, tanpa akun dan tanpa server untuk permainan.

## Menjalankan

Ekstrak ZIP, lalu buka `index.html` di browser ponsel atau komputer. Berkas `mouse-cheese.webp` harus berada dalam folder yang sama dengan `index.html`. Setelah kedua berkas tersedia, permainan tidak membutuhkan internet. Anda juga bisa menyajikan folder ini melalui server web statis apa pun.

## Bermain

1. Pilih jumlah pemain dan isi nama jika diinginkan. Pilih Fall Mouse hanya untuk 6–8 pemain.
2. Tekan **Kocok & bagikan rahasia**. Oper ponsel sesuai giliran. Hanya pemain yang namanya ditampilkan menekan dan menahan tombol untuk melihat peran serta angka. Lepaskan sebelum mengoper.
3. Gunakan aplikasi Cheese Thief Moderator resmi di perangkat lain untuk audio. Letakkan token keju fisik di meja.
4. Pada malam hari, Sleepyhead yang bangun sendirian boleh mengintip satu angka pemain lain melalui tombol tahan di layar malam. Fitur ini bergantung pada kejujuran pemain dan dimatikan pada permainan 4 pemain.
5. Diskusi dan voting dilakukan secara fisik. Tombol buka seluruh rahasia disediakan sesudah ronde selesai.

Follower ditentukan ketika malam sesuai instruksi audio moderator dan jumlah pemain, bukan dibagikan di awal. Pada permainan 4 pemain, setiap orang mendapat dua angka: Sleepyhead memilih satu waktu bangun; pencuri dapat bangun pada keduanya jika berbeda.

Catatan: ponsel bersama tidak dapat memastikan siapa yang berhak mengintip. Jangan membuka aplikasi lain atau menyegarkan halaman di tengah ronde karena rahasia ronde disimpan sementara di memori browser. Pengaturan tema disimpan di perangkat.

Companion ini tidak berafiliasi dengan Jolly Thinkers atau LaudoStudio. Tidak menyertakan audio, gambar, ataupun kartu resmi.
