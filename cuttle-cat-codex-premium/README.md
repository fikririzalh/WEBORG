# Cuttle Cat Codex — Premium Edition

Dashboard interaktif HTML/CSS/JavaScript untuk mempelajari Cuttle, mencoba kalkulator target King, memeriksa Scuttle, dan menyimpan riwayat pertandingan di `localStorage`.

## Menjalankan

Buka `index.html` langsung di browser modern. Tidak ada build step, package manager, framework, atau koneksi internet yang diperlukan untuk fungsi utama.

## Fitur

- Halaman awal: kartu spesial lengkap A–K.
- Ilustrasi SVG kucing unik per rank; tidak memakai satu emoji kucing yang diulang.
- Penjelasan mode Point, Scuttle, One-Off, dan Permanent/Royal.
- Aturan setup, batas tangan, counter chain, proteksi Queen, target King, dan stalemate.
- Filter dan pencarian kartu.
- Checklist penguasaan dengan progres tersimpan.
- Dark mode tersimpan.
- King win calculator.
- Scuttle legality checker.
- Match tracker dan win rate lokal.
- Layout responsif dengan sidebar desktop dan bottom navigation mobile.

## Ruleset

Konten mengikuti ruleset 1v1 modern dari Cuttle Cards. Karena Cuttle memiliki variasi historis, jangan mencampurkan angka King atau efek 5/7/9 dari ruleset lama tanpa menyepakatinya sebelum bermain.
