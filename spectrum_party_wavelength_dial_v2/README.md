# Spectrum Party — Wavelength Dial V2

Buka `index.html` di browser.

Fitur baru:
- 100 spectrum card + CRUD seperti versi sebelumnya.
- Klik kartu -> tombol `Go to Wavelength`.
- Random card -> tombol `Go to Wavelength`.
- Dial digital satu-device.
- Psychic dapat drag target atau `Acak Target`.
- `Tutup Target` menyembunyikan zona skor 2-3-4-3-2.
- Tim penebak drag jarum merah.
- `Buka Hasil` menampilkan target dan skor.
- Fine control kiri/kanan untuk target atau jarum.
- `Ronde Baru` menggunakan spectrum card yang sama dengan target baru.

Board fisik masih bisa dipakai untuk skor tim; web ini hanya companion target/dial.
