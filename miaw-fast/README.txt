SEBUT CEPAT
Board game kategori dan huruf acak, HTML, CSS, dan JavaScript.

CARA MENJALANKAN
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka file index.html menggunakan Chrome, Edge, Firefox, atau Safari.
3. Tidak diperlukan instalasi, server, akun, atau koneksi internet.

CARA BERMAIN
1. Atur waktu ronde, gunakan pilihan cepat atau masukkan durasi kustom 5 sampai 300 detik.
2. Aktifkan atau nonaktifkan opsi Acak Kategori.
3. Tekan tombol Acak & Mulai.
4. Pemain di dunia nyata menyebutkan jawaban sesuai kategori yang berawalan salah satu dari enam huruf.
5. Selesaikan sebanyak mungkin jawaban sebelum waktu habis.

FITUR
- Satu perangkat, tanpa profil atau data pemain.
- Enam huruf unik yang diacak setiap ronde.
- Timer kustom 5 sampai 300 detik.
- Tambah, pilih, ubah, dan hapus kategori.
- Mode terang dan gelap.
- Pengaturan tersimpan otomatis pada browser perangkat.
- Dapat digunakan secara offline.
- Responsif untuk laptop, tablet, dan ponsel.

PINTASAN KEYBOARD
- Space: acak dan mulai ronde.
- Esc: batalkan ronde atau tutup pemberitahuan waktu habis.

STRUKTUR FILE
- index.html: struktur antarmuka.
- style.css: seluruh desain dan tampilan responsif.
- app.js: logika permainan, timer, kategori CRUD, serta penyimpanan lokal.
