VISUAL STRETCH
==============

A local, single-file visual cue / stretching session builder.

HOW TO RUN
1. Extract the ZIP.
2. Double-click index.html.
3. Add images.
4. Set timing and image fit.
5. Click START STRETCH.

KEYBOARD
Space       Pause / Resume
Left Arrow  Previous image
Right Arrow Next image
F           Enter / exit fullscreen
Esc         Browser-native exit fullscreen

PRIVACY
- No account.
- No backend.
- No analytics.
- No external font or library.
- Selected images are referenced locally in the browser using temporary object URLs.

NOTES
- Fullscreen availability depends on browser support and permission.
- If fullscreen is denied, the session still runs in the page.
- For best results, use a current desktop or mobile browser.
