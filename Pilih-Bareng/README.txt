PILIH BARENG — PARTY GAME OFFLINE

CARA MAIN
1. Ekstrak seluruh isi ZIP ke satu folder.
2. Buka index.html di browser. Jangan pindahkan app.js atau style.css dari folder tersebut.
3. Pilih Pass and play (satu ponsel bergiliran) atau Narator + kertas.
4. Mainkan 10 ronde. Pilihan dengan suara terbanyak memberi 1 poin kepada tiap pemain yang memilihnya; jika seri, tidak ada poin.

FITUR
- 100 pertanyaan, 4 pilihan per soal, 10 soal acak per permainan.
- Tombol kembali untuk memperbaiki langkah. Pembatalan suara setelah hasil terbuka meminta konfirmasi.
- Mode terang dan gelap, tampilan ramah ponsel.
- Tidak memerlukan internet atau server setelah file diekstrak.

CATATAN
Permainan berjalan tanpa penyimpanan jika browser membatasi penyimpanan file lokal. Dalam keadaan itu, jangan muat ulang atau tutup tab sebelum permainan selesai. Skor mode Narator + kertas dicatat di kertas.

Pembaruan game dapat dibuat lagi kemudian dengan menambah pertanyaan atau mode.
