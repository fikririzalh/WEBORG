# MIAU! FAKTA MANA?

Single-device trivia party deck.

## Mekanik
Ini mengikuti varian yang diminta: **1 fakta benar + 2 pernyataan palsu**.
1. Web menampilkan tiga baris.
2. Semua pemain menulis tebakan 1 / 2 / 3 di kertas.
3. Balik kartu.
4. Hanya baris yang benar diberi warna hijau + tanda centang.
5. Skor dicatat di luar web.

## Fitur
- 100 kartu seed original
- CRUD pemain P001...
- CRUD kartu Q001...
- Kartu memiliki kategori, 3 pernyataan, truth index, sumber
- Search
- Shuffle tanpa pengulangan sampai deck habis
- Dark/light
- Sound
- localStorage
- Export/import JSON
- Responsive mobile
- Fake flip tanpa mirror
- Scoring tidak ada di web
