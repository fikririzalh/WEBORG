# Grammar Pasture · Lamb & Wolf Edition

Offline HTML/CSS/JS grammar trainer for noun, verb, adjective, and adverb classification.

## Run
Open `index.html` in a modern browser. No server or build step is required.

## Included
- 100 original starter sentences across 4 levels
- Numbered targets with dropdown answers and `Not sure`
- Blank answers allowed
- Enter key submits
- Hints with half-credit scoring
- Complete answer explanations and Indonesian glosses
- Sentence CRUD + search/filter
- JSON export/import
- Vocabulary view generated from the sentence bank
- Progress statistics by level
- Light/dark pastoral Lamb & Wolf theme
- Procedural music/SFX via Web Audio API
- localStorage persistence

## Notes
The app intentionally numbers only words assigned to one of the four trained major word classes. Other word classes (articles, pronouns, prepositions, conjunctions, etc.) can remain unnumbered. `Not sure` is an abstention option, not a fifth word class.
