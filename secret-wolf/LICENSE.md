# License and Attribution

Secret Wolf is an unofficial, non-commercial adaptation of **Secret Hitler**, created by Mike Boxleiter, Tommy Maranges, and Mac Schubert.

The original game is licensed under the **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International License (CC BY-NC-SA 4.0)**. Secret Wolf is distributed under the same license.

License: https://creativecommons.org/licenses/by-nc-sa/4.0/
Original game: https://www.secrethitler.com/

Changes in this adaptation include a farm/sheep/wolf theme, renamed roles and offices, original web UI, single-device pass-and-play role reveal, browser-managed policy deck and board state, procedural audio, light/dark themes, and local browser persistence.

No original Secret Hitler artwork is included in this project.
