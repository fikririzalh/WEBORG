# MIAW FAST ANGKA V3.1

Boardgame tebak angka 2–4 pemain, 1 device.

## Mode Classic
- Target melingkar: P1 → P2 → P3 → P4 → P1.
- Satu pemain mendapat petunjuk dari satu target.
- Fair-round tetap berlaku.

## Mode Fast
- Setiap pemain tetap memiliki satu angka rahasia unik.
- Satu tebakan dibandingkan ke semua pemain lawan sekaligus.
- Contoh 4 pemain: P1 menebak 34, lalu layar result menampilkan karakter P2, P3, dan P4 bersamaan.
- Tiap karakter memberikan hasil: Lebih Tinggi, Lebih Rendah, Tepat, atau Sudah Ditemukan.
- Pemain yang sudah menebak tepat angka lawan akan menyimpan lawan tersebut sebagai ditemukan.
- Pemenang adalah pemain pertama yang menemukan semua angka rahasia lawan.
- Jika lebih dari satu pemain menyelesaikan semua target pada ronde yang sama, hasil seri.

## Menjalankan
Ekstrak ZIP lalu buka `index.html`. Seluruh CSS dan JavaScript berada di file tersebut.
