# MIAU! CRACK 4

Duel codebreaking 2 pemain, 1 device.

## Aturan varian
- Masing-masing membuat 4 digit rahasia.
- Digit harus unik; 0 boleh dipakai termasuk di depan.
- Pemain bergantian menebak kode lawan.
- Feedback hanya menunjukkan posisi yang tepat (hijau).
- Kotak gelap tidak berarti digit pasti tidak ada; hanya posisi itu belum tepat.
- History tebakan privat per pemain.
- Jika Player A memecahkan kode lebih dulu dalam suatu ronde, Player B tetap mendapat attempt pada ronde yang sama.
- Jika keduanya berhasil pada ronde yang sama, hasil seri.

## Fitur
- Single device privacy/pass screen
- History attempt
- Known-position helper
- No duplicate digits
- Dark/light
- Sound
- Responsive mobile
- Nama pemain tersimpan localStorage

Tidak perlu server/npm. Buka index.html.
